### 💰 Kubera – Expense Tracker

A responsive expense tracking web application built using **Next.js, React, and JavaScript**.

- Track income and expenses with categorized transactions.
- Set monthly budgets and monitor budget utilization.
- View spending patterns through interactive charts and analytics.
- Search, filter, and export transaction records as CSV.
- Save data using browser LocalStorage.
- Designed with a responsive interface and PWA support.

**Tech Stack:** Next.js · React · JavaScript · CSS Modules · Recharts · LocalStorage
